# 亲子时间规划｜child-ai-co-planning

一个中文 AI Skill：和孩子一起制订下周时间计划。孩子提出安排，家长确认现实边界，AI 只做整理、核算和指出冲突，不替任何人拍板。

## 怎么用

1. 把本仓库的 `SKILL.md` 放进一个名为 `child-ai-co-planning` 的文件夹。
2. 把该文件夹复制到 `~/.agents/skills/`。
3. 在新的 Codex 对话中输入：`$child-ai-co-planning 我们想一起规划下周`

## 边界

只用必要、脱敏的日程信息。示例均为虚构。
